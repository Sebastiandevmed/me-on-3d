# Preguntas Esenciales para el Cliente

Documento de recopilación de información antes de iniciar un proyecto web. Responder lo más completo posible para acelerar el desarrollo y evitar retrabajos.

---

## 1. Información General del Negocio

1.1. ¿Cómo se llama tu negocio/marca?
1.2. ¿Cuál es tu giro o industria? (ej: joyería, hoteleria, tecnología, alimentos)
1.3. ¿Qué vendes o qué servicio ofreces? Describe tu producto/servicio principal.
1.4. ¿Cuánto tiempo llevas operando?
1.5. ¿Tienes presencia física (tienda, oficina) o solo digital?
1.6. ¿En qué ciudad/país operas principalmente?

---

## 2. Objetivos del Sitio Web

2.1. ¿Cuál es el objetivo PRINCIPAL de la página web?
   - [ ] Vender productos online (e-commerce)
   - [ ] Mostrar servicios y generar leads (contacto/cotización)
   - [ ] Ser vitrina/portafolio de trabajos
   - [ ] Automatizar procesos (ventas, atención, etc.)
   - [ ] Otro: _______________

2.2. ¿Qué acción quieres que el visitante haga al llegar a tu sitio?
   (ej: comprar, escribirte, llamar, ver catálogo, reservar)

2.3. ¿Tienes metas medibles?
   (ej: 100 ventas/mes, 50 consultas/mes, 1000 visitas/mes)

2.4. ¿Qué problema específico quieres resolver con la web?
   (ej: "no tengo dónde vender online", "pierdo clientes porque no tengo presencia digital", "manualizo pedidos por WhatsApp")

---

## 3. Cliente Objetivo

3.1. ¿Quién es tu cliente ideal? Describe su perfil:
   - Edad aproximada:
   - Género:
   - Ubicación:
   - Nivel socioeconómico:
   - ¿Qué le importa cuando compra?

3.2. ¿Cómo llegan los clientes a ti hoy?
   (ej: WhatsApp, redes sociales, boca a boca, mercados, publicidad pagada)

3.3. ¿Qué dispositivo usan más tus clientes? (celular, computador, ambos)

3.4. ¿Qué tan técnico es tu cliente?
   (ej: maneja bien internet, solo usa WhatsApp, necesita algo super simple)

---

## 4. Marca e Identidad Visual

4.1. ¿Ya tienes logo? Si sí, ¿en qué formatos lo tienes?
   (PNG transparente, SVG, AI/PSD, solo JPG)

4.2. ¿Tienes manual de marca o colores definidos?
   (si tienes un archivo con colores, tipografías, etc., compártelo)

4.3. ¿Qué colores asocias con tu marca?
   (ej: negro y dorado para lujo, verde para natural, azul para tecnología)

4.4. ¿Qué sensación quieres que transmita tu sitio?
   - [ ] Lujo / Elegancia
   - [ ] Confianza / Profesionalismo
   - [ ] Cercanía / Calidez
   - [ ] Innovación / Tecnología
   - [ ] Diversión / Joven
   - [ ] Otro: _______________

4.5. ¿Hay marcas o sitios web que te gusten como referencia?
   (enlaces o nombres)

4.6. ¿Hay algo que NO quieras en el diseño?
   (ej: "nada de colores neón", "nada demasiado formal", "sin fotos genéricas")

---

## 5. Contenido

5.1. ¿Ya tienes el contenido escrito? (textos, descripciones, títulos)
   - [ ] Sí, todo listo
   - [ ] Tengo algo pero necesita edición
   - [ ] No, necesito que me ayuden a crearlo
   - [ ] Parcialmente (algunas secciones sí, otras no)

5.2. ¿Tienes fotos propias de tus productos/servicios?
   - [ ] Sí, profesionales
   - [ ] Sí, pero caseras/necesitan edición
   - [ ] No, necesito banco de imágenes o sesión fotográfica
   - [ ] Quiero usar imágenes generadas con IA

5.3. ¿Necesitas secciones específicas?
   - [ ] Catálogo de productos
   - [ ] Lista de servicios con precios
   - [ ] Testimonios de clientes
   - [ ] Blog / Noticias
   - [ ] Preguntas frecuentes (FAQ)
   - [ ] Formulario de contacto/cotización
   - [ ] Chat en vivo o WhatsApp flotante
   - [ ] Otro: _______________

5.4. ¿Tienes textos de marca? (misión, visión, propuesta de valor)

---

## 6. Funcionalidades Técnicas

6.1. ¿Necesitas tienda online? Si sí:
   - [ ] Catálogo simple (sin pasarela de pago)
   - [ ] Tienda con carrito y pago online
   - [ ] Migración desde otra plataforma (Shopify, WooCommerce, etc.)
   - ¿Cuántos productos aproximados?
   - ¿Métodos de pago que necesitas? (PSE, tarjeta, Nequi, Daviplata, etc.)

6.2. ¿Necesitas reserva/citas online?
   - [ ] Sí
   - [ ] No
   - ¿Qué plataforma usas hoy? (Calendly, Google Calendar, etc.)

6.3. ¿Necesitas automatización por WhatsApp?
   - [ ] Sí (bot de ventas, soporte, pedidos)
   - [ ] No
   - ¿Qué proceso quieres automatizar?
   - ¿Ya tienes número de WhatsApp Business?

6.4. ¿Necesitas integración con otros sistemas?
   - [ ] Google Analytics / Meta Pixel
   - [ ] CRM (HubSpot, Salesforce, etc.)
   - [ ] ERP o sistema de inventario
   - [ ] Email marketing (Mailchimp, Brevo, etc.)
   - [ ] Redes sociales (feed de Instagram, etc.)
   - [ ] Otro: _______________

6.5. ¿Necesitas área de clientes/usuarios?
   - [ ] Sí (login, dashboard, contenido restringido)
   - [ ] No

6.6. ¿Necesitas multidioma?
   - [ ] Sí (español + otro idioma)
   - [ ] No, solo español
